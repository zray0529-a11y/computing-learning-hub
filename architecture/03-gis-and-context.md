## 机制一：坐标数值必须带着解释使用

`(100, 200)` 可能是局部模型中的毫米坐标，也可能是某个平面坐标系统中的米坐标。
仅有两个数字，不能判断点在地球上的位置，也不能知道哪一个轴朝向何处。
拿到一份数据时，先把下面的问题回答完整。

| 必查信息 | 为什么会影响结果 |
| --- | --- |
| 坐标参考系统或局部基准 | 决定原点、轴向及数值与空间的对应关系 |
| 轴顺序 | 第一列不一定就是想当然的经度或东向坐标 |
| 单位 | 同一个数值可对应不同的实际长度 |
| 水平与竖向解释 | 平面位置一致，不代表高程基准一致 |
| 数据来源与变换记录 | 决定怎样核对结果和追踪偏差 |

PROJ 官方说明，坐标轴顺序会遵循参考系统的定义，但不同软件接口也可能有自己的约定。[1]
因此，要同时检查源数据说明和调用接口，而不能一律假设“经度在前”。

## 机制二：贴标签与变换坐标是两种操作

PostGIS 的 `ST_SetSRID` 设置空间参考标识，不会改变几何坐标的数值。[2]
`ST_Transform` 则根据源和目标参考系统计算新的坐标。[3]
前者适用于已知道数值所用参考系统、需要补充标识的情况。
如果源参考系统判断错误，后续转换也会建立在错误前提上。

局部模型接入场地时，还可能需要单位换算、平移和旋转。
这些操作的顺序必须明确：先平移再旋转，与先旋转再平移一般不同。
仅在屏幕上拖到“看起来重合”，不会自动补齐可复现的变换记录。

本篇实验演示单位换算和二维刚体变换；它不是两个地理参考系统之间的投影转换。
真实地理转换还应使用适合源、目标及适用范围的工具和变换定义。[3]

## 机制三：面积的单位来自计算方法

在平面坐标中，用同一单位表示边长，得到的面积就采用该单位的平方。
因此，从毫米变成米时，长度缩小 1000 倍，面积数值缩小 1000000 倍。
这可以直接从矩形的“长乘宽”推导，不需要任何 GIS 软件。

PostGIS 对 `geometry` 使用二维平面面积，单位由空间参考决定；
对 `geography` 默认在椭球上计算面积，结果为平方米。[4]
把经纬度数字直接套入平面公式，并不能自动得到平方米。
选择测量方法之前，应先问自己需要的是局部平面量还是地球表面的量。

## 最小实验：单位换算后，检查旋转和平移

一个 4000 × 3000 毫米的教学矩形，先换算成米。
再将其逆时针旋转 90°，最后平移到局部目标原点 `(100, 200)` 米。
预期面积和对角线长度在刚体变换前后保持一致。

```python
from math import hypot

raw_mm = [(0, 0), (4000, 0), (4000, 3000), (0, 3000)]

def area(points):
    pairs = zip(points, points[1:] + points[:1])
    return abs(sum(x1 * y2 - x2 * y1 for (x1, y1), (x2, y2) in pairs)) / 2

def to_world(point):
    x, y = point
    return (100 - y, 200 + x)

local_m = [(x / 1000, y / 1000) for x, y in raw_mm]
world_m = [to_world(point) for point in local_m]
diagonal = hypot(world_m[2][0] - world_m[0][0], world_m[2][1] - world_m[0][1])
assert area(local_m) == area(world_m)
assert diagonal == 5.0
print(f"raw_area_mm2={area(raw_mm):.0f}")
print(f"local_area_m2={area(local_m):.2f}")
print(f"world_vertices={world_m}")
print(f"world_area_m2={area(world_m):.2f}")
print(f"diagonal_m={diagonal:.2f}")
```

确切预期输出：

```text
raw_area_mm2=12000000
local_area_m2=12.00
world_vertices=[(100.0, 200.0), (100.0, 204.0), (97.0, 204.0), (97.0, 200.0)]
world_area_m2=12.00
diagonal_m=5.00
```

如果只把原始数据的单位标签改成米，而不除以 1000，面积数值仍是 12000000。
标签与数值就会矛盾，这与“只指定参考系统不会重新计算坐标”的区别相呼应。
面积公式在本实验中用于按边界顺序给出的简单无孔多边形；不是完整的几何有效性检查器。
实验使用能精确表示的简单数值；一般浮点运算的结果比较应采用说明过的误差容许范围。

## 把模型与场地叠加时怎样核对

用已知的多个控制点核对方向、距离和位置，避免只比较一个看起来正确的角点。
另行检查高程解释、单位及变换顺序，并保留源坐标到目标坐标的参数或转换定义。
若几何用于面积或相交查询，还应检查边界是否自交、是否缺边以及孔洞表达是否正确。
这些是数据检查步骤；具体精度要求应来自任务依据，本文没有给出统一容差。

## 闭卷问题

1. 将一个图层的参考标识改成目标参考系统，为什么不等于完成坐标转换？
2. 毫米坐标只除以 1000，面积数值为何要变化 1000000 倍？
3. 两份数据的平面位置重合，是否足以证明模型高程也正确？

<details>
<summary>展开参考答案</summary>

1. 改标识只改变解释坐标的元数据；真正转换必须根据正确的源定义重新计算坐标。
2. 面积由两个长度相乘，两个方向各缩小 1000 倍，所以面积数值缩小 1000000 倍。
3. 不足。高程还取决于竖向基准、单位、局部原点和实际转换过程，需要单独核对。

</details>
