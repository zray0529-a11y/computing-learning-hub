## 本轮课程可读性复核

按18个教学单元逐条核对“术语抢跑、前置倒置、图文脱节、公式跳步”。每章开头接回对应图解的具体例子，保留建筑类比的失效边界、标准库实验、可检查输出和闭卷问题。以下是本轮处理结果；没有把外部评审的比喻直接当成技术结论。

| 教学单元 | 已落实的调整 |
|---|---|
| [01 计算](chapters/01-computation.md) | 补齐 `8+4+0+1=13`、八比特一字节、码点与UTF-8；图灵机与停机问题移到可选延伸 |
| [02 硬件](chapters/02-hardware.md) | 用档案库、工作台与手中数值解释SSD、RAM、寄存器的数据搬运；降低微架构术语的前置负担 |

几处建议经核实后作了纠正：`#101`是文件内实例标识而非行号，`GlobalId`不是自动永恒不变；返回值不天然只读；TCP不是独占专线；首字母目录不自动带来常数级查找；普通MD5不能用作密码存储方案；Brick词汇统一不等于任何楼宇自动互通。各章就近列出机制、条件和来源。图谱实际为39个概念、68条关系；没有为了符合评审中的“40节点”描述虚增节点。

## 文档与文件检查

本轮验证脚本扫描103个文件，其中55个Markdown文件，解析368处本地链接引用，最终检查结果为0个错误。网站目录实际收录45份文档、18个交互图解与3张正文流程图。

验证脚本检查本地链接及标题锚点、代码围栏配对、异常替换字符、未填标记，以及必要入口和许可文件。

网页检查覆盖离线内容完整性、内部导航与搜索、18课图解节点/高亮/自测、手机阅读卡片顺序和恢复、三维图谱与主题切换、前沿来源与日期校验。折叠块检查改为逐文档比对原文与生成页，避免把允许增减的教材折叠数量写成固定数字。网络与GIS的SVG另作栅格化目视检查；这不等同于真实手机触摸测试。

公开文件另经过内容审阅：使用通用叙述、虚构数据与空白进度模板；没有导入个人履历、实际学习记录、工作项目资料、私有仓库引用或既有仓库历史。

检查工具会跳过`learning/`、`*.local.md`和其他忽略目录，并拒绝读取指向仓库外或非公开记录的链接目标。已用临时虚构笔记复现旧的过滤遗漏，再验证修正后该笔记不被读取或执行；临时探针不属于本仓库交付文件。

## 复现方法

在仓库根目录运行：

```bash
node scripts/build-site.mjs
node --test --test-concurrency=1 tests/*.test.mjs
python3 -B scripts/verify.py
git diff --check
```

成功时返回退出码0，输出中的`errors`为空。脚本只依赖标准库，不发起网络请求，不写入读者文件；执行示例时使用临时工作目录。

只对信任的仓库版本运行检查，因为它会执行Markdown中的Python代码。脚本没有实现进程沙箱，也不声称能安全运行任意他人提交的代码。
