# 技术史与概念中的十个常见误区

历史脉络能帮助理解技术为什么出现，但年份、定义、前提和证据需要分别核对。本页整理十类常见混淆，使用公开的一手资料作为查证入口。

导航：[总入口](index.md) · [历史与概念地图](02-history-and-map.md) · [学习方法](03-learning-method.md)

资料核对日期为2026-11-15。每项只主张其注明范围内的核验；没有把打开摘要写成全文审读，也没有独立复现引用论文的全部实验。

### 1. 摩尔定律：1965 与 1975 的说法要分开

1965 年的原始预测是集成电路元件规模约每年翻倍；1975 年调整为约每两年翻倍。把“1965 年提出每两年翻倍”合并成一句，会丢失修订过程。这里描述的是产业中的经验趋势与目标，不能直接推出某个程序速度、芯片频率或 AI 能力也按相同比例增长。

证据：[Intel 的摩尔定律说明](https://www.intel.com/content/www/us/en/newsroom/resources/moores-law.html)（访问 2026-11-15；已核对正文中 1965/1975 的区分及其并非自然定律的说明，未据此验证页面的未来产业预测）。

### 2. CAP：把失败模型与术语放回结论

CAP 的核心约束是：在允许网络分区、消息可能丢失的模型中，复制读写对象无法在所有执行中同时保证线性一致性与规定的可用性。把它记成“三项任意选两项”，会误以为网络分区是产品经理可以取消的功能。

- **C：** 这里是线性一致性；不能直接替换成 ACID 中的业务约束一致性。
- **A：** 到达非故障节点的每个请求最终得到符合操作语义的响应；它不是平均在线率，也不是“返回任何错误码就算可用”。
- **P：** 模型允许节点组之间的消息无法传递；重点是出现这种失败时仍要求什么。

例如 A、B 两个副本断联，A 已确认一次写入，B 随后收到读取。B 无法从现有信息判定 A 是否写入；无限等待可能破坏可用性，返回旧值可能破坏线性一致性。工程上还要分别分析读写操作、恢复流程和正常状态下的延迟。

证据：[Gilbert 与 Lynch 原始证明](https://groups.csail.mit.edu/tds/papers/Gilbert/Brewer6.pdf)（访问 2026-11-15；已核对 §2 的定义及 §3.1 的不可能性定理与分区构造）；[作者发表目录](https://groups.csail.mit.edu/tds/lynch-pubs.html)（同日；核对论文的 2002 年记录）。目录中的 [Brewer2.pdf](https://groups.csail.mit.edu/tds/papers/Gilbert/Brewer2.pdf) 是 2012 年回顾文章，不能当成 2002 年原论文标注。

### 3. PageRank：随机浏览者不等于整个搜索系统的算法分类

1998 年的 Google 论文讨论网页抓取、索引、超链接结构与排序；PageRank 依据链接图传递权重，并用随机浏览者模型解释。随机浏览者是一种建模直觉，不能据此把整个搜索系统归类为“拉斯维加斯算法”。学习时应分开抓取、倒排索引、相关性匹配与链接排序。

证据：[Brin 与 Page 论文全文](https://snap.stanford.edu/class/cs224w-readings/Brin98Anatomy.pdf)（访问 2026-11-15；已核对 §2.1 的 PageRank、迭代计算与随机浏览者解释）；[Google Research 书目信息](https://research.google/pubs/the-anatomy-of-a-large-scale-hypertextual-web-search-engine/)（同日；核对作者、题名与 1998 年）。

### 4. Agent 的历史不能从一本教材或 LLM 开始

Agent 适合用感知、状态、决策、行动和环境反馈来理解。SRI 的 Shakey 项目在 1966—1972 年间已经研究规划、路径寻找与物体操作。因此，1995 年教材可以作为系统化教学的入口，不能未经学术史考证就宣称它“首次正式奠基 Agent”；《心智社会》也不应被写成唯一思想起源。

证据：[SRI 的 Shakey 项目说明](https://www.sri.com/hoi/shakey-the-robot/)（访问 2026-11-15；核对项目年代与任务能力）。该材料足以反驳“Agent 随 LLM 才出现”，不足以确认 Agent 概念的唯一首创者。

### 5. A2A 的发布日期与协议作用要明确

Google 的 A2A 发布公告日期是 **2025-04-09**。记录一个协议事件时，应标注确切事件类型和日期。公告将 A2A 定位于 Agent 间通信和任务协作，并说明它与提供工具、上下文连接的 MCP 互补；接入协议本身不保证任务正确、权限合理或多个 Agent 一定优于单个 Agent。

证据：[Google A2A 发布公告](https://developers.googleblog.com/en/a2a-a-new-era-of-agent-interoperability/)（访问 2026-11-15；核对发布日期、用途及与 MCP 的关系；未据此声称 2026 年的全部规范和实现都与首发版本一致）。

### 6. 开放权重、开源软件与开放训练资料需要分别记录

权重可下载，只说明某些模型参数可以获得。能否使用、修改、再分发，要读对应版本的许可；训练代码和训练数据信息是否提供，还要另行检查。模型系列也不能因为其中一个版本开放，就整体标成相同许可。

证据：[OSI 开源软件定义](https://opensource.org/osd)（访问 2026-11-15；核对源代码、修改、再分发及用途限制等条款）；[OSI 开源 AI 定义 1.0](https://opensource.org/ai/open-source-ai-definition)（同日；核对数据说明、代码、参数及四项自由）。这是采用 OSI 定义时的分类依据，不是对所有模型逐一完成的许可审计。

### 7. RLHF 改善指令遵循，不构成正确性证明

InstructGPT 以示范数据、偏好比较与强化学习改善目标分布上的回答表现。论文仍报告编造事实、偏差和其他失败。由“更符合标注者偏好”推到“推理必然正确”没有根据；推理能力应另外用任务、答案校验、分布外表现和失败率衡量。可验证奖励与偏好奖励的可用信号也不同，不能统称为同一种保证。

证据：[InstructGPT 论文](https://arxiv.org/pdf/2203.02155)（访问 2026-11-15；核对摘要的训练过程与评价结论、§5.2 的偏好来源、§5.3 的模型局限；没有声称复现全部实验）。

### 8. Scaling Laws 不是“规模决定一切”的定理

Kaplan 等研究的是特定设置下语言模型交叉熵损失与模型、数据、训练计算之间的经验关系。Chinchilla 研究固定训练计算预算下模型规模与训练 token 的配置。它们帮助提出可检验的资源分配假设，不能直接证明所有能力、可靠性或商业价值都随参数量单调增长；训练最优也不自动等于包含推理成本后的部署最优。

证据：[Kaplan 等论文](https://arxiv.org/pdf/2001.08361)与[Chinchilla 论文](https://arxiv.org/pdf/2203.15556)（访问 2026-11-15；已核对两篇摘要、研究目标及预算口径，未独立复现实验或验证外推范围）。

### 9. 2024 年诺贝尔化学奖的完整归属

该奖的一半授予 David Baker，表彰计算蛋白质设计；另一半由 Demis Hassabis 与 John Jumper 共享，表彰蛋白质结构预测。若主题聚焦 AlphaFold，可以讨论后半项贡献，但不能把它当作整届奖项的全部获奖信息。

证据：[瑞典皇家科学院 2024-10-09 公告](https://www.kva.se/en/news/the-nobel-prize-in-chemistry-2024/)（访问 2026-11-15；已核对完整获奖名单、分配与授奖理由）。

### 10. 初次公开、会议发表与产品上线是不同日期

Self-Consistency 的 arXiv 记录显示首次提交于 **2022-03-21**，ICLR 发表在 2023 年。ReAct 则首次提交于 **2022-10-06**，随后有 2023 年会议版本。保留两个日期及事件类型，比选择一个年份制造精确感更可靠。

证据：[Self-Consistency 版本记录](https://arxiv.org/abs/2203.11171)、[ReAct 版本记录](https://arxiv.org/abs/2210.03629)（访问 2026-11-15；这里只核验页面的提交记录与会议标注，不能据此声称已通读两篇论文的全部方法和实验）。

## 继续查证时怎样做

遇到历史“首次”论断，要区分手稿、预印本、会议、正式出版与产品上线；涉及多人贡献时，不凭一份年表指定唯一首创者。

遇到定理，记录对象、假设、保证与反例。例如可计算性与不完备性讨论有各自的形式条件，不能泛化为“计算机无法知道真理”。

遇到成本、性能或能力结论，查清数据集、模型版本、资源范围、基线和指标。教学示意与实际测量分别说明。

自测：用一句话分别解释为什么“CAP三选二”“开放权重就是开源”“RLHF保证推理正确”会误导。答案应指出缺少的定义、前提或证据。
