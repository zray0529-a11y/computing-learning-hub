# 中英术语索引

这里只提供进入概念的最短路径。掌握一个词的标准是能解释机制、预测结果并给出边界；一句话定义不能替代对应章节。每组标题链接到主要学习与来源入口。

## 1. [计算与表示](chapters/01-computation.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 比特 bit | 表示两种可区分状态的信息单位 | 不必物理上恰好是0伏与1伏 |
| 字节 byte | 现代通用系统中通常指8比特 | 一个字符不一定一个字节 |
| 二进制 binary | 用两个数码的位置表示法 | 0和1本身不包含对象的语义 |
| 编码 encoding | 把内容映射为约定的表示 | 编码不等于加密 |
| Unicode | 统一字符编号与相关规则的标准 | 字符编号与UTF-8字节序列不同 |
| 布尔值 Boolean | 真或假的逻辑值 | 业务未知不能总塞成假 |
| 命题 proposition | 可讨论真假的陈述 | 含糊需求未必是精确定义的命题 |
| 谓词 predicate | 输入对象后得到真假判断的规则 | 判断结果仍依赖输入和定义 |
| 可计算性 computability | 是否存在算法解决规定的问题 | 有算法不代表成本可接受 |
| 停机问题 halting problem | 不存在对所有程序和输入都正确的通用停机判定算法 | 不表示任何具体程序都无法分析 |

## 2. [硬件与资源](chapters/02-hardware.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 指令 instruction | 处理器按架构定义执行的基本操作 | 高级语言一行不等于一条机器指令 |
| 指令集 ISA | 软件可使用的机器指令与行为约定 | 与具体芯片内部实现不同 |
| CPU | 负责通用指令执行的处理器 | 核数多不保证所有程序都更快 |
| GPU | 擅长特定大规模并行运算的处理器 | 小任务和数据传输可能抵消收益 |
| 内存 RAM | 运行时存放数据和程序状态的工作空间 | 与持久磁盘容量不同 |
| 显存 VRAM | GPU可使用的设备内存资源 | 模型权重不是唯一占用项 |
| 缓存 cache | 复用较近或较快的数据副本 | 命中率、失效与一致性都有代价 |
| 存储 storage | 持久保存数据的介质与系统 | 数据保存了不表示备份可恢复 |
| 带宽 bandwidth | 单位时间可搬运的数据量 | 与单次响应延迟不同 |
| 瓶颈 bottleneck | 当前限制整体性能的环节 | 最昂贵的设备未必是瓶颈 |

## 3. [程序与语言](chapters/03-programming.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 值 value | 程序操作的数据 | 表示相同不一定类型相同 |
| 变量 variable | 程序中引用或保存值的名字与位置机制 | 不同语言的绑定和存储语义不同 |
| 类型 type | 对值及允许操作的分类约定 | 类型正确不保证业务正确 |
| 函数 function | 按约定接收输入并产生结果或副作用的单元 | 打印与返回不是一件事 |
| 返回值 return value | 函数交给调用方的结果 | 屏幕显示了内容不等于调用方拿到结果 |
| 类 class | 某类对象的数据与行为组织方式 | 不必把所有程序都写成类 |
| 对象 object | 具有身份、状态或行为的程序实体 | 编程对象不自动对应现实实体 |
| 枚举 enum | 用一组命名成员表示有限选项 | Python的enumerate是带序号遍历，不是同一概念 |
| 编译器 compiler | 把一种程序表示转换成另一种的工具 | 输出不一定直接是本机机器码 |
| 解释器 interpreter | 按某种程序表示执行其含义的系统 | 编译与解释可在同一运行链中结合 |
| 运行时 runtime | 程序执行所依赖的支持环境 | 语言语法与运行环境要分开 |
| 异常 exception | 用专门控制路径报告异常状况的机制 | 捕获异常不等于问题已解决 |

## 4. [数据结构与算法](chapters/04-algorithms.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 算法 algorithm | 为一类问题定义的可执行求解过程 | 算法与某种语言实现不同 |
| 列表 list | 顺序组织的一组元素 | 不同实现的操作成本不同 |
| 字典／映射 map | 从键查询关联值的数据结构接口 | 哈希实现有碰撞，不能总写成绝对O(1) |
| 集合 set | 关注成员关系与去重的集合接口 | 记录去重不等于现实实体去重 |
| 栈 stack | 后进先出的组织方式 | 与任意位置访问不同 |
| 队列 queue | 常见为先进先出的待处理序列 | 不自动提供持久性和消息可靠性 |
| 树 tree | 具有层次结构的一类图 | 真实关系不总能强行塞成单父节点树 |
| 图 graph | 节点与边组成的关系表示 | 每条边的业务含义必须明确 |
| 大O Big O | 描述成本随规模增长的上界阶 | 不是某台电脑上的毫秒数 |
| BFS／广度优先搜索 | 按层扩展图的遍历方法 | 最少边数与任意带权最短路不同 |

## 5. [操作系统与执行](chapters/05-operating-systems.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 程序 program | 描述计算的代码与相关表示 | 文件存在不等于正在运行 |
| 进程 process | 程序运行中的资源与执行实例 | 相同程序可以有多个进程 |
| 线程 thread | 进程内的执行路径 | 多线程不保证同时并行 |
| 并发 concurrency | 多项任务在时间上交错推进 | 单核也可以有并发 |
| 并行 parallelism | 多项计算在同一时刻实际执行 | 不保证整体线性加速 |
| 异步 asynchronous | 发起与完成处理分离的协作方式 | 不自动让CPU计算更快 |
| 锁 lock | 协调对共享资源的访问 | 锁使用错误会阻塞或死锁 |
| 虚拟内存 virtual memory | 为进程提供受管理的地址空间抽象 | 不等于内存不足时无限变大 |

## 6. [网络与Web](chapters/06-networks.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| IP | 网络层寻址与分组传递的一组协议 | IP地址不等于稳定业务身份 |
| DNS | 查询域名相关记录的系统 | 解析成功不保证应用服务正常 |
| 端口 port | 传输层端点的数字标识组成部分 | 端口不是物理插口 |
| TCP | 提供可靠有序字节流的传输协议 | 不知道应用消息边界和业务成功 |
| UDP | 提供数据报传输的协议 | 可靠性可由上层协议另行设计 |
| HTTP | 定义请求、响应与资源语义的应用协议 | 返回200不自动代表业务正确 |
| TLS | 为通信提供认证、机密性和完整性保护的协议 | 加密不能替代资源授权 |
| URL | 标识资源位置和访问方式的地址表示 | 链接可打开不等于许可可复制全部资料 |
| API | 程序之间交互的接口约定 | API不一定是网络接口 |
| JSON | 文本数据交换格式 | 格式正确不保证字段含义正确 |
| SSE | 服务端以事件流向客户端发送更新的机制 | 与双向消息通道不同 |
| WebSocket | 支持连接上的双向消息通信的协议 | 不自动保证断线重连后的业务去重 |

SSE与WebSocket的额外定义依据：[WHATWG标准](https://html.spec.whatwg.org/multipage/server-sent-events.html)、[RFC6455](https://www.rfc-editor.org/rfc/rfc6455)，2026-11-15读取相关说明；实际兼容性另查目标环境。

## 7. [数据库](chapters/07-databases.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 主键 primary key | 唯一标识一行的键约束 | 名称不天然稳定或唯一 |
| 外键 foreign key | 表达并约束对另一表记录的引用 | 引用存在不证明现实关联正确 |
| 模式 schema | 数据结构与约束的定义 | 灵活文档仍需要契约 |
| 查询 query | 描述需要读取或计算的数据结果 | 执行计划与查询语义不同 |
| JOIN | 按条件组合关系中的记录 | 条件不完整可能产生重复组合 |
| 索引 index | 为某些访问模式建立的辅助结构 | 有写入和存储代价 |
| 事务 transaction | 把多步数据库操作组织成提交单元 | 不自动包含外部服务动作 |
| ACID | 原子性、一致性、隔离性和持久性的概括 | C与CAP中的C不是同一口径 |
| 隔离 isolation | 并发事务之间的可见性与影响约束 | 不同级别的保证不同 |
| 空间索引 spatial index | 加速空间候选查找的索引 | 附近不等于相同或归属 |

## 8. [工程协作](chapters/08-software-engineering.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 仓库 repository | 保存版本内容与历史的组织单位 | 托管地址与本地工作区不同 |
| 提交 commit | 记录一组版本状态与父版本关系 | 提交成功不代表验收通过 |
| 分支 branch | 指向某条版本进展的可移动引用 | 不是必须复制整个目录 |
| 合并 merge | 按版本关系整合变化 | 无文本冲突不代表无语义冲突 |
| PR／pull request | 提出并审阅一组仓库变更的协作入口 | 不是程序运行请求 |
| 单元测试 unit test | 检查局部单元行为 | 不证明整体系统可用 |
| 集成测试 integration test | 检查多个部分的契约配合 | 仍不覆盖所有现实输入 |
| CI／持续集成 | 频繁集成并自动检查变更的工程实践 | 自动运行不等于检查有价值 |
| CD | 持续交付或持续部署，需说明具体口径 | 两种含义的发布边界不同 |
| 回退 rollback | 恢复到可接受版本或状态 | 应用回退不一定撤销数据变更 |

## 9. [分布式系统](chapters/09-distributed-systems.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 事件 event | 某次发生事实的可处理记录 | 与当前状态快照不同 |
| 事件流 event stream | 持续到达或可重放的事件序列 | 顺序必须说明范围 |
| 消息队列 message queue | 在发送与消费之间缓冲消息 | 可靠性取决于具体协议与配置 |
| 分区 partition | 可能指数据分片，也可能指网络隔离 | 先看语境再解释 |
| 复制 replication | 多处维护数据副本 | 与分片不同 |
| 共识 consensus | 在指定故障模型下对值或日志达成一致 | 不等于模型多数投票 |
| 幂等 idempotence | 重复操作不增加额外业务效果 | 与强一致性互不替代 |
| 最终一致性 eventual consistency | 满足条件且停止更新后副本收敛 | 不是正确性万能保证 |
| CAP | 分区故障模型下的一致性与可用性约束 | 不是无条件三选二 |
| 背压 backpressure | 下游通过机制限制上游推进速度 | 不等于无限扩展缓冲区 |

## 10. [机器学习](chapters/10-math-and-ml.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 特征 feature | 模型使用的输入表示 | 有相关性不代表因果作用 |
| 标签 label | 监督任务中的目标记录 | 人工标签也可能有噪声 |
| 训练 training | 根据数据与目标调整参数 | 不等于部署和日常调用 |
| 推理 inference | 使用模型计算输出 | 不必然包含逻辑推理或权重更新 |
| 损失 loss | 衡量预测与训练目标差异的量 | 与业务价值指标不必一致 |
| 梯度 gradient | 函数对参数局部变化的导数信息 | 不是自动到达全局最优的保证 |
| 精确率 precision | 预测为正的样本中实际为正的比例 | 与召回率分母不同 |
| 召回率 recall | 实际为正的样本中被识别出的比例 | 与总体准确率不同 |
| 泛化 generalization | 对目标分布中未见数据的表现 | 训练集高分不能代替 |
| 过拟合 overfitting | 对训练细节适应过强而泛化不足 | 需要结合独立评估判断 |

## 11. [LLM](chapters/11-llm-and-rag.md)与[Agent](chapters/12-agents.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| token | 模型使用的离散输入输出单位 | 不总等于一个汉字或单词 |
| embedding／嵌入 | 把对象映射到向量表示 | 语义相似不等于事实相同 |
| Transformer | 以注意力等结构处理序列表示的网络架构 | 架构名称不是可靠性等级 |
| 上下文 context | 当前调用中提供给模型的信息 | 与长期保存的资料不同 |
| KV cache | 复用生成过程中部分注意力计算的缓存 | 不等于长期知识库 |
| SFT | 利用监督示例微调模型参数 | 不保证所有新任务都正确 |
| RLHF | 利用人类反馈等信号改进模型行为的一类方法 | 偏好改善不是事实证明 |
| RAG | 结合外部检索材料与生成的系统方法 | 不是把文档上传就永远自动读到 |
| 工作流 workflow | 按明确路径组织步骤的过程 | 包含模型也可以是固定流程 |
| Agent | 根据目标和观察选择行动的系统角色 | 定义依研究与工程语境而异 |
| 工具调用 tool calling | 发出结构化调用并获取执行结果 | 请求已生成不等于动作已完成 |
| MCP | AI应用接入工具和数据的协议约定 | 不自动授予权限或保证内容正确 |
| A2A | 支持Agent间互操作的协议方向 | 连接成功不等于协作有效 |

## 12. [安全可靠](chapters/13-security-and-reliability.md)与[空间系统](chapters/14-spatial-systems.md)

| 术语 | 一句话入口 | 常见误区 |
|---|---|---|
| 认证 authentication | 建立身份 | 与允许做什么不同 |
| 授权 authorization | 决定身份对资源的动作权限 | 前端隐藏按钮不等于后端限制 |
| 提示注入 prompt injection | 外部内容试图影响可信任务指令的风险 | 检索到的文字不自动成为授权 |
| SLI／SLO | 测量指标与目标水平 | 统计窗口、分母和好请求定义要明确 |
| 可观测性 observability | 利用日志、指标、追踪理解系统状态 | 未观测不能算正常 |
| 坐标参考系 CRS | 定义坐标与现实位置关系的规则 | 相似数字不能直接套合 |
| 实体 entity | 有稳定身份、可关联状态的对象 | 名称、模型节点和相机不天然同一 |
| 观察 observation | 有来源与时间的采集或判断记录 | 与永远有效的事实不同 |
| 3DGS | 用三维高斯表示与渲染场景的一类方法 | 外观逼真不自动提供语义与碰撞 |
| 数字孪生 digital twin | 面向用途连接现实对象与数字表示的系统 | 有三维模型不自动具备实时闭环 |

## 常见工具名的落点

Kafka放在事件流与系统解耦一层，Qdrant可放在向量检索基础设施一层，MinerU可放在文档解析与结构抽取一层。它们不是同一类模型或互相替代的完整系统。

依据：[Kafka官方介绍](https://kafka.apache.org/intro/)、[Qdrant官方文档](https://qdrant.tech/documentation/)、[MinerU官方仓库](https://github.com/opendatalab/MinerU)，2026-11-15读取用途说明。安装、版本、许可与性能需在实际使用时另核查；本版没有安装这些产品。
