# 网页与离线使用说明

## 在线阅读

打开[学习库网页](https://zray0529-a11y.github.io/computing-learning-hub/)，可使用课程目录、全文搜索、页内目录、代码复制、收藏和已读标记。页面适配电脑与手机。在线地址的首次打开需要联网，不需要读者购买服务器或公网 IP。

网站公开展示已有公开教材，不包含读者个人资料。搜索在当前设备完成，不把查询词发送给外部搜索服务。

## 图解与完整教材

14 章计算机基础和 4 个建筑专题默认以图解打开。先看全图，再点击步骤标签或前后箭头，高亮关注的部件和关系。每张图只展开本章的一个核心机制；下方的类比边界、常见误区和预测题帮助核对理解。

二进制章节可以拨动四个开关；数据库章节可以逐步比较成功提交与主键冲突回滚；RAG 章节可以切换有无检索资料，观察证据约束下的回答示例。这些是本机教学演示，未连接真实数据库或模型服务。

首页的四个二进制开关也可直接点击，或用 Tab 定位后按空格/回车切换；算式与十进制结果会即时更新。独立的“进入第 01 章”链接可继续阅读完整讲解。顶部细线显示当前页面的滚动位置，卡片与页面切换带有轻量动效；系统开启“减少动态效果”后会直接显示内容和定位结果。

点击“完整教材”查看原来的全部概念、代码实验与来源，再点“先看图解”返回。搜索结果及原文小节链接会打开完整教材，确保相关文字可见。小屏中的机制图可在图框内左右滑动，也可使用“放大图解”。

## 知识图谱、协作场景与历史沿革

从左侧“知识图谱 · 3D”或首页的新入口打开知识地图。39 个概念连接到全部 18 个图解章节；搜索、分区筛选和知识点选择框均可定位概念。点模型或标签后，右侧显示定义、具象类比、关联解释及返回教材的链接。

关系图谱中的“理解基础”箭头从基础指向后续概念，是建议的理解路径；“用到”从使用者指向所用机制；“共同协作”没有先后含义。位置和模型大小不表示概念难度或重要性。

协作场景用图书预约、依据展馆资料回答、虚构小楼状态三个故事，每个分六步，高亮当前参与的概念。步骤是教学推演，说明对应系统可以怎样设计，并不连接真实业务、传感器或模型服务。

历史沿革选取 1936—2020 年间 16 个代表性论文或事件，逐项说明当时的问题、贡献以及与现有章节的学习连接，提供原始资料链接。日期可能表示收稿、报告或发表时间，详见每项标记；时间先后不等于学习先修或已证实的历史因果。

三维视图支持拖动旋转、滚轮/双指缩放、缩放按钮与复位，不自动旋转。设备不能启用 WebGL 2 时，会尝试用 Three.js 的 SVGRenderer 显示同一套模型与相机，标记为“轻量 3D”。点击“列表视图”可以使用同一套概念、关系和场景说明；两条绘图路径均不可用时自动进入列表阅读。模型是用于辨认概念的微缩示意，机制与类比边界以旁边说明为准。

点选模型、标签、关联概念或知识点选择框后，相机会平移到所选概念，保留当前观察角度与缩放；拖动、缩放、复位或离开页面会中止移动。深色主题同时调整三维背景、平台、标签和关系线，保留原有关系类型与选中高亮。轻量 3D 也使用这些主题与定位行为。

## 离线阅读

在网页右上角选择“离线下载”，保存完整 HTML 文件。使用支持 JavaScript 的浏览器打开下载文件，即可阅读全部打包正文、18 张图解和知识地图，使用分步讲解、互动演示、自测、搜索、章节切换与答案展开，无需安装软件或启动服务器。三维运行时、轻量绘图模块与概念、场景、历史数据均内嵌。个别手机的文件预览器不执行网页脚本，应选择用浏览器打开。

离线文件是下载时的内容快照。以后教材更新，需要重新下载；外部参考资料和 GitHub 链接仍需联网。离线文件仅包含本仓库公开材料，不包含外部论文、网页或第三方教材全文。

## 学习记录

收藏、已读标记与阅读位置只保存在当前浏览器的本地存储，不上传到公共仓库，也不跨设备同步。“已读”表示自己标记读过，不代表已掌握。浏览器清理数据、无痕窗口结束或切换设备后，记录可能不再存在。

文件形式的网页是否持久保留记录取决于浏览器；即使本地存储不可用，正文和搜索仍可使用。离线下载不会打包个人阅读记录。

## 维护网页

教材 Markdown 是正文来源。维护者修改教材后，GitHub Actions 会构建网页并发布。构建只读取显式内容清单，不会把后来增加的个人笔记自动发布。

本地检查与构建需要 Node.js 22 或更新版本，以及用于原有教材检查的 Python 3：

    node --test tests/*.test.mjs
    node scripts/build-site.mjs
    python3 -B scripts/verify.py

生成的网页位于构建输出目录。Markdown 解析器 marked 17.0.5 随源码提供，保留其原始 MIT 许可；浏览器阅读时无需联网加载该解析器。已有三张流程图以 SVG 内嵌，源图变更后须重新生成并更新图源摘要，避免显示过期图表。

新增图解维护在 `site-src/lessons/` 的三份模块中；正文更新涉及对应机制时，应同步审阅图解、步骤与自测。构建验证 18 个核心主题覆盖、SVG 安全边界、步骤焦点、关联路径和自测唯一正确选项。离线包包含这些图形与交互，无远程字体或 CDN 依赖。

知识地图的数据维护在 `site-src/atlas-data.mjs` 与 `site-src/atlas-history.mjs`；界面与模型分离。构建检查概念 ID、有效章节、边关系类型、场景引用与历史来源。Three.js r180 和 OrbitControls 固定在 vendor 中，构建验证上游 Git blob 摘要后合并为离线脚本，保留 MIT 许可。图形按需渲染，离开页面时释放图形资源和事件监听。

通用交互动效位于 `site-src/motion-upgrade.mjs` 与 `site-src/motion-upgrade.css`，由同一构建脚本内联打包。动效不依赖 CDN；页面切换会刷新观察目标，减少动态效果和缺少增强 API 的浏览器仍可完整阅读与操作。
