# 用户动效补丁集成

来源：用户提供的 `site-src-motion-upgrade.zip`（四个源码补丁与集成说明）。目标是在现有图解知识库中启用这些优化，并更新 GitHub Pages。

## 实施范围

1. 把通用动效作为独立源码模块和样式内联到现有离线构建，适配实际卡片类名。
2. 在真实路由渲染结束后刷新滚动进度和渐显观察目标；主题切换派发同步事件。
3. 将首页二进制示意改为四个原生按钮，实时显示位权算式，保留独立的章节入口。
4. 让 Three.js 的 WebGL 与 SVG 两条渲染路径同步深浅主题，同时保留关系颜色、高亮和箭头含义。
5. 点选概念后有限时长地平移相机与观察目标；用户操作、隐藏和销毁时取消，减少动态效果时直接定位。

## 验证与发布

- 检查视图过渡的回调只执行一次、缺少 API 的回退，以及相机定位不改变角度/缩放、可中断且无持续动画循环。
- 运行全部 Node 测试、教材验证、构建与最终内联脚本语法检查。
- 以已核对的远端 main 为父提交，更新 GitHub 并等待 Pages 工作流成功。
- 在真实发布地址检查首页交互、路由、深浅主题与轻量 3D 定位。

## 构建顺序

现有视觉集成测试会读取 `_site/index.html`；原有站点测试也会重新构建该文件。因此 CI 先显式构建，再以 `--test-concurrency=1` 运行所有测试，避免全新检出时缺少产物或同时读写文件。验收应从不包含旧构建产物的源码副本开始。

## 参考视觉对齐

用户随后提供完整的 `computing_learning_hub_motion_upgrade.html`，明确偏好其颜色与光影。对齐其深墨绿页面（#070d0a）、卡片（#0e1914）、内嵌面板（#13231b）、薄荷绿高光与青蓝/紫/琥珀分类色；应用环境渐变、半透明导航、柔和阴影和局部高光。调整真实知识图谱的材质及标签以统一视觉，不引入原型的 CDN 依赖或缩减为五个示意节点。

首次访问默认深色，保留浏览器中明确保存的深浅主题选择。小号文字及按钮采用满足阅读对比的近似参考色值。验证包含主题恢复、完整构建、既有交互与发布后的视觉检查。
