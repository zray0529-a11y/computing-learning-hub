# 手机竖屏与 Agent 前沿补充实施计划

> **For agentic workers:** Use superpowers:executing-plans or superpowers:subagent-driven-development for the assigned task.

**Goal:** 手机逐卡学习，新增有日期、有来源、有能力边界的 Agent 前沿入口，并安排持续核查。

**Architecture:** 复用静态离线阅读器和现有图解 DOM；窄屏按步骤显示单张学习卡。前沿内容独立保存为 JSON，经构建校验后与阅读器一同内联；更新任务读取官方来源并更新同一份数据。

**Tech Stack:** 原生 JavaScript、CSS、现有 Three.js；无新增运行依赖。

**Spec:** 用户本轮请求：手机竖屏好操作、一屏一个知识点；补充 Anthropic、DeepSeek 等 Agent 前沿并持续更新。

## 实施选择与约束

- 选择复用现有图解的逐卡阅读；独立移动站点会造成两份教材，强制滚屏会妨碍长内容和图谱操作。
- 采用来源核验后静态发布；页面展示最近核验时间，离线版是下载时的快照。不能把页面时钟当新闻更新。
- 卡片允许纵向滚动；前后按钮、目录、完整教材及无障碍操作均保留。
- 研究原型、测试版、正式能力分开标记；厂商实验不改写为普遍成功保证。
- 只处理公开资料和虚构教学例子，不引入用户工作项目。

## Review Focus

- 360px 竖屏、较矮屏幕和安全区：按钮可达，内容不裁切。
- 图解深链接：所指卡片打开后仍可阅读，切换章节清理事件监听。
- 前沿日期：核验日期不冒充发布日，过时快照有提示。
- 来源与输入：HTTPS 来源、已知章节、唯一 ID、未知路由有可用回退。
- 主题、桌面和离线：两种主题可读，桌面完整阅读不退化，无外部运行资产。
