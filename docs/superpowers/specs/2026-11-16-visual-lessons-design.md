# 图解优先的计算机知识库

## 目标与范围

读者反馈正文过于密集、难以理解。将 14 章基础课与 4 个建筑专题的默认入口改为图解阅读：用空间关系、数据流和状态变化解释一个核心机制，支持分步高亮与即时自测。原始教材仍完整可读、可搜索、可下载。

## 方案与决策

考虑过在长文中插入插画、把文章整体转成图，以及新增图解阅读层。采用第三种：每章一张经过审校的机制图、3–4 步解释、一个误区或类比边界、一道即时自测；少数关键概念提供可操作演示。前两种分别不能解决阅读负担、容易丢失必要细节。本次按用户要求直接改进现有网站，不增加账户、后台或依赖。

## 交互与视觉

- 首页改为图解导览，按“表示与计算／程序与系统／数据与智能／空间与应用”提供视觉入口与典型问题。
- 18 个主题默认显示图解，完整教材入口清晰。来自正文搜索、目录和原始片段链接的跳转必须能显示对应全文。
- 图形使用准确的内联 SVG，颜色辅助区分类别；文字和箭头承担信息表达。不能用装饰图代替机制图。
- 分步按钮可键盘操作，活动状态通过文字和形状共同表达。保持图本身不移动，避免阅读时跳动。
- 二进制、数据库事务、检索增强生成提供可点击示例，明确它们是简化教学模型。
- 小屏图形可单独横向查看并可放大，页面本身不横向溢出；深色主题、减少动态效果、离线文件继续可用。

## 内容与隐私约束

- 只使用现有公开教材与虚构例子，不引入个人、客户或工作项目内容。
- 图解事实与对应章节一致，明确类比局限；图解不宣称覆盖整章。
- 原始 Markdown 不因视觉呈现而丢失。保留已有收藏、已读、本机存储、外部来源与授权。
- 无远程字体、CDN 或运行时请求；离线包必须包含新增图解和交互。

## 交付与验证

提交代码并通过现有 GitHub Actions 更新原网址。验证 18 个主题覆盖、SVG 与步骤关联、唯一正确选项、交互状态计算、原文链接和离线资源完整性；复用原有教材验证；独立审阅；线上核对首页、典型图解、互动、全文切换和搜索。
