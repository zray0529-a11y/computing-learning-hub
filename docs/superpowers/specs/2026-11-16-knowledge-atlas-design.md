# 三种视角的知识地图

用户希望在现有 GitHub Pages 教材加入知识点关系、具象协作和历史沿革，优先 Three.js。直接实现已有公开站点的增强，无需再确认可逆的设计选择。

新增知识图谱入口与首页推荐。39 个概念覆盖 18 个现有章节；关联必须说明语义和方向。图谱、协作场景、历史沿革共用概念 ID，并链接回原有图解与完整教材。场景采用网页查询、基于资料回答、虚构建筑数字孪生。历史日期是代表性文献或事件锚点，附来源，不将先后顺序描述成必然影响或先修关系。

Three.js 渲染可交互的空间与具象模型，不用装饰性图片冒充机制。中文 HTML 标签、关系说明面板、概念列表共同支持可理解的操作。支持鼠标/触摸、重置、缩放；不自动旋转。无 WebGL 时保留完整列表、关系与场景阅读。

固定版本运行时随单文件 HTML 打包。无运行时 CDN、外部模型、后端或新账号。原有全文搜索、学习记录、图解、离线下载继续可用。
