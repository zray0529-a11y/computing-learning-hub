# 开放学习库网页设计

## 目标与范围

为已有公开教材提供可直接打开的 GitHub Pages 阅读入口，适配手机与电脑。保留十四章基础、四个建筑专题、学习方法、十二周计划、实验、术语与来源；不将任何个人信息、私有项目或个人记录加入仓库。

## 方案选择

维护者选择原生 HTML、CSS、JavaScript 与构建期 Markdown 渲染：无需在线脚本或字体，下载一个 HTML 即可离线阅读所有正文并搜索。在线网站托管在现有仓库的 Pages。通用文档框架会引入额外安装与主题配置，逐页按需下载会使离线覆盖不完整，因此本轮不采用。该实现选择由维护者作出，用户授权了建站与发布目标。

## 阅读体验

首页提供课程入口和继续阅读；侧栏按基础课程、建筑专题、学习与实践、资料索引分组。正文保留表格、代码、折叠答案和三张流程图，提供页内目录、上下篇、复制代码、收藏和已读标记。已读不表示已掌握。中文全文搜索覆盖正文，支持直接定位章节。浅色为默认主题，提供深色切换。

## 离线与数据

生成页面内嵌全部公开正文、样式、脚本和流程图，不依赖 CDN。下载按钮导出不含个人浏览状态的完整 HTML；外部参考资料与源码仓库链接仍需联网。阅读位置、收藏、已读状态仅写入当前浏览器本地存储；存储被禁用时正文仍可阅读。文件模式不承诺跨文件或跨设备同步。

## 内容与维护

使用显式公开文件清单，禁止递归扫描后自动发布。教材 Markdown 是唯一正文来源。保留 CC BY 4.0 与 MIT 及第三方许可；网站原创代码采用 MIT。三张已有 Mermaid 图构建为内嵌 SVG，并绑定源代码摘要以防过期。GitHub Actions 在主分支教材或网站文件变化后构建并发布。

## 完成标准

教材原有校验通过；中文搜索、路径与锚点、折叠答案、完整离线打包通过针对性检查；浏览器验证首页、章节、搜索与窄屏布局；Pages 部署成功，实际打开最终网址后交付。
