# 计算机与智能系统：知识总览

本学习库围绕“信息怎样表示、程序怎样执行、系统怎样协作、模型怎样学习、行动怎样受约束”建立基础知识链。读者可以按顺序学习，也可以从具体问题进入，再回补先修。

## 三条学习路径

| 路径 | 起点 | 预期产物 |
|---|---|---|
| 计算机基础 | [14章目录](chapters/index.md)、[12周计划](04-learning-plan.md) | 能解释并重做一个小型数据处理系统 |
| 建筑与空间应用 | [4个建筑分类](../architecture/README.md) | 通过构件、参数、坐标与状态练习计算机方法 |
| 问题驱动 | [问答路由](05-question-routing.md)、[术语表](07-glossary.md) | 回答一个问题，完成一个最小检查 |

## 核心知识如何连接

| 层次 | 主要内容 | 需要回答的问题 |
|---|---|---|
| 表示与计算 | 二进制、编码、逻辑、硬件 | 机器处理什么，怎样处理，有什么边界？ |
| 程序与算法 | 控制流、函数、接口、数据结构 | 怎样把规则写清楚，并选择正确且合适的处理方法？ |
| 系统与通信 | 操作系统、网络、数据库 | 怎样运行、共享、通信并保存数据？ |
| 工程与分布式 | 契约、测试、版本、消息、部分失败 | 多人多服务协作时怎样保持可检查性？ |
| 学习与智能 | 数学、机器学习、LLM、RAG、Agent | 怎样从数据产生输出，怎样核对并约束行动？ |
| 可靠性与空间 | 权限、证据、时间、坐标与实体 | 怎样把计算结果连接到有边界的空间应用？ |

历史演进与学习依赖是两种关系，不能互相替代。学习路线的说明见[历史与概念地图](02-history-and-map.md)。

## 每章怎样使用

先理解一个机制，再预测小实验结果；运行并解释差异，关闭材料回答闭卷问题，最后改变一个条件检查迁移。类比只负责帮助进入概念，正式定义与反例负责限定边界。

[学习方法](03-learning-method.md)把检索、间隔、自我解释、交错、例题渐隐和反馈转成具体活动。研究证据与本库的教学安排分别说明，不把某种方法写成适用于所有人的保证。

## 一个贯穿案例

六个离线实验用虚构设备记录演示“输入→校验→去重→存储→按实体和时间查询→给出带出处的观察或未知”。

这个案例连接编程、算法、数据库、分布式、检索和工作流。实践入口见[实验目录](practice/index.md)。它没有接入真实设备、LLM或外部服务；脚本通过只能证明对应教学机制在测试条件下可运行。

建筑分类另外使用构件、几何参数、场地坐标与设备观察等题材。它们是独立练习，不要求读者来自某个职业、公司或项目。

## 怎样记录进步

公共仓库提供[空白学习模板](../templates/learning-progress.md)。读者复制到本地`learning/`目录，分别记录解释、操作、迁移与延迟保持；该目录已加入忽略规则。

没有作答证据时标为未评估。教材阅读量、AI代写成功和参考脚本运行结果，都不能代替独立能力证据。详细规则见[进度与复习](06-progress-and-review.md)。
