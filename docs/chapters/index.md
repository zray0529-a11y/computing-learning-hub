# 十四章基础知识

- [C01｜计算、逻辑与信息](01-computation.md)：从二进制、编码和逻辑进入可计算性与抽象。
- [C02｜硬件与存储层次](02-hardware.md)：理解CPU、GPU、缓存、内存与磁盘的协作及瓶颈。
- [C03｜程序、语言与接口](03-programming.md)：掌握对象、控制流、函数、执行方式和契约边界。

- [C05｜操作系统](05-operating-systems.md)：解释进程、线程、虚拟内存、文件和同步。
- [C06｜网络与Web](06-networks.md)：沿DNS、传输层、TLS、HTTP和业务协议理解一次请求。
- [C07｜数据库](07-databases.md)：从实体与观察建模进入SQL、索引、事务和数据约束。
- [C08｜软件工程](08-software-engineering.md)：将需求落实为接口契约、版本变更、测试与验收证据。
- [C09｜分布式系统](09-distributed-systems.md)：处理部分失败、重复、乱序、一致性与消息传递。
- [C10｜数学与机器学习](10-math-and-ml.md)：连接向量、概率、优化、数据划分与模型评价。

- [C13｜安全与可靠性](13-security-and-reliability.md)：检查身份、授权、输入信任、观测指标和恢复机制。
- [C14｜空间与数字孪生](14-spatial-systems.md)：连接坐标、几何、实体、图结构、视觉表达和时效状态。
