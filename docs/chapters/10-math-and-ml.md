# 10 数学与机器学习：从数据拟合到可检验的判断

## 核心判断

机器学习用数据调整函数的参数，再对未见样本作出预测。训练集表现好只说明拟合能力；是否能处理新地点、新天气和新任务，需要独立评估。

先修：[程序](03-programming.md)、[算法](04-algorithms.md)。数学先学到能解释一个具体机制，再决定是否深入证明。

## 四种数学工具分别干什么

| 工具 | 最小理解 | 能解释的问题 |
|---|---|---|
| 逻辑与集合 | 条件、集合、关系、量词 | 如何定义正例与任务边界 |
| 线性代数 | 向量、矩阵、点积、线性变换 | 图像、特征和坐标怎么表示 |
| 微积分 | 导数、梯度、链式法则 | 参数变化怎样影响损失 |
| 概率统计 | 条件概率、抽样、均值和不确定性 | 预测和评估为什么可能不稳 |

向量是一组有顺序的数。矩阵可以把一组输入组合成另一组数；神经网络反复组合线性变换与非线性函数。点积既可以表示线性评分，也可以出现在相似度计算中，但它的意义取决于向量如何构造和归一化。

对一个最小模型 y_hat = w*x，平方损失是 (w*x-y)^2。损失对w的导数为 2*x*(w*x-y)。梯度下降沿降低损失的方向更新w；学习率决定每一步走多远。反向传播高效计算网络中这些导数，它是求梯度的方法，优化器才利用梯度更新参数。[Google ML课程](https://developers.google.com/machine-learning/crash-course)

## 一次手算更新

```python
x, y, w, learning_rate = 2.0, 6.0, 1.0, 0.1
before = (w * x - y) ** 2
gradient = 2 * x * (w * x - y)
w = w - learning_rate * gradient
after = (w * x - y) ** 2
print(round(w, 2), round(before, 2), round(after, 2))
```

预期：`2.6 16.0 0.64`。这只展示一个样本上的一步改进，不证明对其他样本有效。把学习率改得很大，损失可能增加；“训练更多”也并非每一步都让验证表现改善。

## 训练、验证与测试要分工

训练集用于调参数；验证集用于选择模型、阈值和超参数；测试集用于在选择完成后估计泛化表现。反复查看测试结果再调方案，测试集就被间接用来做选择了。

相机帧高度相似，随机拆帧可能让同一位置同一时段的近重复图片进入训练和测试，造成看起来很好的分数。切分应匹配真实部署目标：要推广到新相机就考虑按相机分组；要预测未来就考虑按时间切分。样本数量、采集覆盖和标注口径都要记录。

建筑类比：做过同一栋楼的相似楼层，不等于能处理另一种结构体系。类比能帮助理解分布变化，但模型并不以工程师的方式理解建筑；它利用的是训练目标下学到的统计规律。

## 不同学习方式

| 方式 | 学习信号 | 例子与边界 |
|---|---|---|
| 监督学习 | 输入与目标标签 | 用标注画面训练拥挤分类器 |
| 自监督学习 | 从数据本身构造预测目标 | 预测被遮挡内容或后续token |
| 无监督学习 | 无显式任务标签的结构目标 | 聚类可能发现模式，但不自动知道类别语义 |
| 强化学习 | 行动后得到奖励或反馈 | 学习策略；奖励设计与环境覆盖影响结果 |

训练好的模型在推理时计算输出，通常不会因你多问一次就自动更新权重。把新样本写入记忆库、改提示词、更新模型参数，是三个不同动作。

## 模型架构解决的瓶颈不同

传统规则系统把知识显式写成条件；统计学习从样本估计规律；深度网络学习多层表示。它们可以组合，不能用“新一代已经取代上一代”解释所有系统。

CNN利用局部连接和权重共享处理空间模式；循环网络按序处理状态；Transformer通过注意力混合位置之间的信息。这些是计算结构，不是智能等级。检测模型输出框和类别，VLM可生成语言描述，但两者都需要任务级验证。

训练过程中的损失与业务指标也不同。让文本预测损失下降，不保证积水识别的误报率下降；优化平均成绩也可能掩盖夜间或特殊天气的失败。

## 指标必须跟着错误代价走

设一次教学评估有：TP=8、FP=2、FN=4、TN=86。精确率=8/(8+2)=0.8，召回率=8/(8+4)≈0.667，准确率=(8+86)/100=0.94。

准确率94%看着很高，但仍漏掉了三分之一的真实事件。指标要结合正例占比、样本规模、标注质量及漏报和误报代价。[Google 分类指标官方说明](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall)

模型给出的“置信度0.9”也不应未经校准就解释为“现实中90%正确”。如果要作为决策概率，需要在相关分布上检查校准。没有观察到的情况应该允许输出未知。
