# 个人学习记录的使用方式

公共教材只提供模板，不维护任何读者的真实学习进度。需要记录时，把[空白模板](../templates/learning-progress.md)复制到自己的本地`learning/`目录，再按实际证据填写。

## 四种证据分开记录

| 维度 | 要观察什么 | 例子 |
|---|---|---|
| 解释 | 能否说明问题、机制与边界 | 解释事务为什么需要统一提交或回滚 |
| 操作 | 能否独立完成并核对结果 | 修改查询，检查空结果与重复记录 |
| 迁移 | 换数据或约束还能否选择方法 | 将设备查询改成构件属性查询 |
| 延迟保持 | 相隔一段时间还能否提取和使用 | 下次学习前重新预测一个新例子 |

“未评估”不等于零分；零分只用于实际尝试后有对应证据的情况。评分方法和帮助程度见[学习方法](03-learning-method.md)。

## 每次只保留必要信息

记录日期、概念、题目、自己的预测或操作、实际结果、提示程度、纠错理由和下次检查条件。个人记录中也优先使用虚构或已获授权的数据。

复习先从记忆中回答，再查教材。遇到错误先定位概念、单位、步骤、边界或环境因素，再用一个变式检查修正。

公共贡献应是可复用的解释、匿名化的教学问题或可复现的代码修正。学习者的身份、工作文件、成绩、客户资料和真实对话留在其自行管理的记录中。

## 复习如何安排

本次独立完成且变式稳定时，可以逐步拉长间隔；依赖提示或概念有误时，下次优先回访。没有统一适用于所有内容的最佳日历，具体依据见[间隔练习说明](03-learning-method.md)。

模板不会创建提醒、自动采集成绩或同步任何服务。工具需要写入记录时，应依学习者的明确要求操作。
